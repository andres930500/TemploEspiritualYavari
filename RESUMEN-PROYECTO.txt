RESUMEN DEL PROYECTO
====================

Proyecto: Landing comercial de servicios esotéricos para Colombia
Estado: Preparación técnica y comercial; contenido real todavía pendiente
Fecha del resumen: 21 de octubre de 2026


1. OBJETIVO DEL PROYECTO
-------------------------

Landing page one-page orientada a:

- Mercado colombiano.
- Visitantes procedentes de Google Ads y búsquedas orgánicas.
- Captación de contactos mediante WhatsApp Business.
- Presentación clara y profesional de servicios espirituales.
- Desarrollo estático, rápido y preparado para Vercel.


2. STACK TECNOLÓGICO
--------------------

- Astro 7.4.2.
- TypeScript estricto.
- Tailwind CSS 4.
- Plugin oficial de Tailwind para Vite: @tailwindcss/vite.
- JavaScript nativo.
- Renderizado estático SSG.
- npm.
- Git.
- Hosting previsto: Vercel.

No se utilizan:

- WordPress.
- Next.js.
- React.
- Vue.
- Angular.
- jQuery.
- Bootstrap.
- Bibliotecas pesadas de animaciones.

14. RENDIMIENTO
---------------

Reporte:
PERFORMANCE-AUDIT.md

Resultados verificables del build:

- CSS generado: aproximadamente 21.7 KB sin comprimir.
- 8 imágenes en la página principal.
- 1 imagen eager.
- 7 imágenes lazy.
- 8 atributos sizes.
- 0 scripts externos activos.
- Sin React, Vue ni hidratación de frameworks.
- Sin dependencias de runtime innecesarias.
- Se mantiene prefers-reduced-motion.
- Se mantienen estados de foco y navegación por teclado.

No se ha ejecutado Lighthouse porque el entorno no dispone de Chrome ni del
comando lighthouse.

Por lo tanto, todavía no se pueden confirmar estas metas:

- Lighthouse móvil de 90 o superior.
- LCP menor de 2.5 segundos.
- INP menor de 200 milisegundos.
- CLS menor de 0.1.
