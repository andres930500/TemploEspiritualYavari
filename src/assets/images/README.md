# Imágenes

- `hero/`: imagen principal del primer pantallazo.
- `services/`: ilustraciones asociadas al catálogo editable.
- `master/`: espacio provisional para la presentación del maestro; no representa a una persona real.
- `social/`: imágenes rasterizadas para Open Graph y redes sociales.

Las ilustraciones actuales son SVG originales y provisionales. Para reemplazar una imagen, conserva el campo correspondiente en `site.ts` o `services.ts`, mantén una relación de aspecto equivalente y actualiza el texto alternativo. Astro procesará los recursos importados mediante `astro:assets`.
